## السبب الجذري

### 1) ملف PDF مبعثر
المولّد الحالي `src/lib/pdf-client.ts` يستخدم `pdf-lib` + `arabic-persian-reshaper` ثم **يعكس السلسلة يدويًا** ويُسطّر النص بـ `wrapText` يقطع على المسافات قبل التشكيل. النتيجة المرئية في الملف الذي أرسلته:
- العنوان والكلمات بحروف معكوسة ("بصمة" تظهر "ةمصب"، "adventure" تظهر "erutnevda").
- كل كلمة تظهر معزولة عن جارتها لأن `wrapText` يحسب العرض قبل التشكيل ثم نقلب كل سطر، فيختلّ ترتيب الكلمات والمسافات.
- الصور لا تُقصّ فعليًا — لكن "الإطار" الملوّن خلفها يظهر بحجم البطاقة الكاملة بينما الصورة `contain` تترك أشرطة فيروزية أعلى وأسفل، فيبدو وكأن الصورة مُؤطَّرة بشريط مقطوع.

أيّ علاج جزئي على `pdf-lib` (bidi/shaping يدوي) سيبقى هشًّا مع العربية. الأسلم: نترك المتصفّح يرسم النص العربي بمحرّكه الأصلي.

### 2) تداخل الهيدر
`Header` في `src/routes/__root.tsx` صفّ واحد فيه: شعار كبير (h-14/16) + اسم العلامة + 4 روابط + زرّ اللغة. على عرض ~786px وأقل تتزاحم العناصر فوق بعضها (خاصة بالعربي مع شعار كبير).

## الإصلاح

### أ) إعادة بناء مولّد PDF — HTML → Canvas → jsPDF

**حزم جديدة**: `jspdf` و`html2canvas-pro` (الـ pro يدعم ألوان `oklch` من Tailwind v4).

**ملف جديد `src/components/StoryPdfTemplate.tsx`**: مكوّن React يُنشئ صفحات A4 جاهزة للالتقاط داخل حاوية off-screen (موضوعة `position: fixed; left: -10000px`، عرض 794px ≈ A4 بـ 96dpi، `dir="rtl"` للعربي).

تخطيط كل صفحة:
```
┌── A4 (794×1123) ──┐
│ شريط فيروزي علوي  │
│  ┌─────────────┐  │
│  │   الصورة    │  │  object-cover داخل بطاقة بنسبة 4:3
│  │   (cover)   │  │  بإطار مدوّر — لا أشرطة فارغة
│  └─────────────┘  │
│  نص الصفحة بخط    │
│  Tajawal،         │  ← المتصفح يرسم العربي صحيحًا
│  محاذاة يمين،     │     مع تشكيل/ربط طبيعي
│  line-height 1.9  │
│ ────────────────  │
│ صفحة 3 من 5 ◆ بصمة حكاية + شعار صغير │
│ بصمة حكاية — جزء من نظام معروف        │
└───────────────────┘
```
الغلاف وصفحة الشكر بنفس المنطق مع تكبير العنوان وحبّات الأجواء (chips).

**خط Tajawal**: نُحمّله عبر `<link>` في `__root.tsx` (Google Fonts) — يكفي للالتقاط، ولا نحتاج TTF/fontkit بعد اليوم.

**ملف جديد `src/lib/pdf-client.ts` (إعادة كتابة)**:
```ts
export async function buildAndDownloadStoryPdf(a: StoryPdfAssets) {
  // 1) ركّب React Root مؤقّت في حاوية off-screen
  // 2) انتظر تحميل كل صور الصفحات (Promise.all + img.decode)
  // 3) لكل صفحة: html2canvas(el, { scale: 2, useCORS: true, backgroundColor: "#FFFBF5" })
  // 4) jsPDF a4 portrait: pdf.addImage(canvas.toDataURL("image/jpeg", 0.92), ...)
  // 5) pdf.save(filename) ثم فكّ التركيب
}
```
الصور تُحمَّل بـ `crossOrigin="anonymous"`؛ روابط Supabase الموقّعة تُرجع CORS صالح.

**شعار الزاوية والعلامة المائية**: نستخدم `brandLogoUrl` كصورة عادية داخل القالب، فيلتقطها html2canvas بالحجم الصحيح.

### ب) لا تغيير في الخادم
`getStoryPdfAssets` يبقى كما هو. تُحذف بقايا `tajawal-fonts.server.ts` و`@pdf-lib/fontkit` و`arabic-persian-reshaper` من الحزمة (تنظيف).

### ج) إصلاح الهيدر المتجاوب

في `src/routes/__root.tsx` `Header`:
- على ≥ md: تخطيط حالي مع شعار h-14.
- على < md: شعار h-10 + اسم العلامة بحجم أصغر + قائمة منسدلة (Sheet من shadcn) خلف زرّ هامبرغر. زرّ اللغة يبقى ظاهرًا. الروابط تنتقل إلى داخل الـ Sheet.
- استبدال `flex` الجامد بـ `gap` صغير و`min-w-0` على اللوغو حتى لا يدفع العناصر.

كذلك نقلّل padding الهيدر (`py-2.5`) ونمنع التفافه بـ `flex-nowrap`.

## التحقق

1. تشغيل تدفّق كامل: مستخدم → طلب 5 صفحات → تأكيد الإدارة → تحميل PDF.
2. `pdftoppm` على الملف الناتج وفحص بصري:
   - "بصمة حكاية" تُكتب صحيحة الاتجاه والوصل.
   - النص العربي لكل صفحة مقروء بدون عكس أو كسر كلمات.
   - الصور تملأ بطاقتها بدون أشرطة لون.
   - الترقيم والتذييل ولون الثيم سليمون.
3. فحص الهيدر على عرض 360/414/768/1024 — لا تداخل، الشعار والاسم وزرّ القائمة في صفّ واحد.
